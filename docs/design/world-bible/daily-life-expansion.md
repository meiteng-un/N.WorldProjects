# ホテルの日常と外域の余白

【仮】追加案。既存の世界観・階用途・NPC配置の確定事項は統合設計書を参照。具体的な配置、災厄の正体、四人が合流した経緯は未確定のまま扱う。

| 足りなかった場面 | 追加案 | プレイヤーに伝わること |
|---|---|---|
| 人が見えない時間帯の生活感 | 売店の棚に途中まで並べた品、乾燥待ちの網、閉店後の受取籠。どれも営業時間の固定を要求しない | 静かでも住民が暮らしている |
| 遠征から戻った直後 | 泥を落とす道具と、濡れた記録を広げる台。荷物の扱いは物語上の演出から始める | ホテルは攻略拠点でもあり帰る場所でもある |
| 暮らしと超技術の接点 | 館内の古い配線札に、増設分だけ別書体のラベルが付く。点検記録には「交換可能」と「触れず報告」の区別 | 古いホテルを修繕しながら使ってきた |
| 目視と観測の食い違い | 観測メモに採取日時・場所の呼び名・誰が確認したか・確度を添える | 記録があっても今日の安全は保証されない |
| 外域交易の薄さ | 交換箱の見本と希望品が一致する場合だけ取引。通貨を受け取る相手でも品目は限定 | ホテルの経済が外域にそのまま広がってはいない |
| 管理区画の見せ方 | 一般側からは閉じた扉越しに低い機械音が聞こえる。詳細説明は許可イベントに回す | 防護・供給があることは感じられるが全貌は明かされない |

外域から戻れない場合に備える判断は、撤収・迂回・報告を依頼の正常な結末として扱う。住民の死亡やホテル崩壊を依頼失敗の結果に設定しない。証拠の欠落は「未確認」のまま残し、世界規模の真相に結び付けない。

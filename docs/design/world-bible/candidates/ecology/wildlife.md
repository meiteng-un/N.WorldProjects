# 原生生物・外域の生態

【仮】14種。食性と敵対性は別々に設定し、観察だけで帰れる場面を含める。物理採取できる生物、物質化を要する怪異、退避しかない現象を混同しない。

| 排水たぬき | 側溝と水路。雑食 | 人の物音に隠れる | 残飯があると夜に戻る。追い詰めると威嚇 | 泥の手形 |
| 石背猪 | 石垣と藪。雑食 | 距離があれば採食を続ける | 仔が近いと警戒。長雨後は地面を掘る | 掘り返した地面 |
| 窓縁きつね | 廃屋と草地。肉食寄り | 視界の外に回って離れる | 濃霧では鳴き声だけ先に聞こえる | 毛・足跡 |
| 塔燕 | 屋上と高い開口部。虫食 | 人に近づかず飛び回る | 強風時は低く飛ぶ。営巣場所に近づくと旋回 | 空の巣材・抜け羽 |

| 棚地衣 | 湿った外壁。光合成 | 接触しても動かない | 長雨で色が濃くなる | 染料試料 |

# 道具・武器・防具・部品

【仮】既存512件の地域別バリエーションとは別の用途を持つ案。装着・所持・使用条件は採用時に確定します。

| ID末尾 | 名称 / English | 区分 | 用途 | 限界・取扱い |
| --- | --- | --- | --- | --- |
| echo-plumb | 残響下げ振り / Echo Plumb | 道具 | 狭い空洞へ下ろして内部の深さと横穴の有無を推定する | 崩落や怪異の安全判定はできない |
| stain-paper | 境界にじみ紙 / Boundary Blotter | 道具 | 同じ地点で時間をずらして置き、異常エネルギーの変動を帯で比較する | 色は相対値。古い試験紙だけでは現在を判断できない |
| brine-needle | 塩分針 / Brine Needle | 道具 | 淡水・汽水の切り替わりを測り、飼育水や釣り餌を選ぶ材料にする | 飲用可否は別検査 |
| cold-clamp | 冷間圧着鉗子 / Cold Crimp Pliers | 道具 | 火気を避けたい場所で端子や留め輪を圧着する | 取り外した端子は再使用不可 |
| murmur-fork | 微振動音叉 / Murmur Fork | 道具 | 動作中の機械の振れを比べ、異常振動の記録を取る | 原因や修理手順の自動表示なし |
| threadguard | 糸払い鉤槍 / Lineclearing Glaive | 武器 | 穂先の返しで絡みつく糸状障害を引き寄せて切る | 引き寄せ不可の怪異には通用しない。狭所では不利 |
| hush-buckler | 響止め小盾 / Hush Buckler | 武具 | 正面の一撃で盾に当たったとき、金属の反響を抑える | 背後や足音には効かない。静音と衝撃吸収は別 |
| brake-blade | 制動短刀 / Brake Knife | 武器 | 刃の背で細い紐を受け、指を刃から離して切断できる | 重装甲向けではない |
| wade-gaiter | 水際脚絆 / Wader Gaiters | 防具 | 浅い泥の侵入を防ぎ、靴の泥詰まりを遅らせる | 浸水・深水圧・酸欠は防がない |
| ear-valve | 反響弁耳当て / Echo-Valve Earmuffs | 防具 | 装備中、突発音だけを和らげる | 連続音や情報の聞き逃しは別問題。プレイヤーの音量設定を上書きしない |
| drain-collar | 排液カラー / Drain Collar | 専用部品 | 対応する採取器の継手に付き、残液を別容器へ流して次の試料への混入を減らす | 適合する径が必要。排液容器は別 |
| frangible-skid | 剥離滑り子 / Breakaway Skid | 接着部品 | 荷台や盾の縁に接着し、床に引きずるときに接着片を先に削る | 摩耗で脱落する。耐久修理や衝撃防御とは別 |

# エンチャント採用候補

【仮】既存の火力・熟練度・巻取り・魚信の強化系列を増やすのではなく、付与で新しい条件付き機能を持たせる案。装備・施術・消費の数値は未定。

| ID末尾 | 名称 / English | 対象と発動 | 効果 | 代償・制約 |
| --- | --- | --- | --- | --- |
| drain-seal | 滴止めの印 / Drip Seal | 試料容器・蓋を閉じる | 移送中に口から漏れる分だけを減らす | 破損容器や溢れには無効 |
| dry-margin | 余白乾燥 / Dry Margin | 資料ケース・濡れた紙を入れる | 書かれた部分から水が広がるのを短時間抑える | 既に消えた文字は戻らない |
| last-bearing | 最後の方位 / Last Bearing | 方位具・手動で目印を記録 | 機器の観測が乱れた時、直前に記録した方位を示す | 古い記録のラベル付き。現在位置や経路は示さない |
| shear-gap | 一拍の刃離れ / Shear Gap | 作業鋏・連続裁断中 | 繊維が刃に噛んだ際、次の一押しで外しやすくする | 対象を切りきる力は増えない |
| soft-land | 着地札 / Landing Seal | 搬送箱・荷下ろし時 | 箱の内側の一度の衝撃を緩める | 外から受けた全ダメージを打ち消さない。再施術が必要な案 |
| temper-gap | 温度継ぎ / Temper Bridge | 調理容器・工程切替 | 火から下ろした直後だけ温度変化を緩める | 加熱・冷却そのものを早めない |
| mute-mark | 残響留め / Echo Pin | 観測機材・観測時 | 自機の動作音が測定に混ざった区間を記録に印す | 周囲に聞こえる音は消えない |
| cinder-ring | 火の粉返し / Cinder Ring | 野営用囲い・設置中 | 囲いの外への火の粉を減らす | 結界・無風・安全地帯を生成しない |

# 部品・強化・耐久の数値案

【仮】以下の値は同じ武器個体に付く各層を比較するための案。

| 層 | 仮値・条件 | 運用 |
|---|---|---|
| スコープ | 視野角12°、重量＋0.35 kg | 専用取付。弾の威力・射程は増えない |
| 消音器 | 発射音の届く距離×0.60、重量＋0.25 kg | 専用取付。音による反応システムと接続した場合の値。命中音・足音は別 |
| 排液カラー | 残液混入の強度−35% | 専用取付。適合径と排液容器が必要 |
| 剥離滑り子 | 接触摩耗の60%を滑り子側へ、耐久20 | 素材接着。0で脱落。武器の修理や胴のダメージ軽減とは別 |
| 刃素材の接着 | 斬撃ダメージ＋8%、重量＋0.18 kg | 一例。接着中のみ。外しても個体の使用履歴を維持 |
| Modifier「手元重心」 | 攻撃後の振り止め時間−12%、振り出し時間＋8% | 工程で付く個体差。総攻撃間隔が短くなるとは限らない |
| Modifier「薄肉成形」 | 重量−15%、最大耐久−12% | 容器用。強化後の現在耐久は新上限に収める |
| エンチャント「滴止めの印」 | 閉蓋中の漏出−50% | エンチャント枠の効果。ひび割れと溢れに無効 |
| Ego「いつもの止め処」 | 目的繊維の切断終点の約0.15秒前に小さな合図 | 使い込みの条件を満たした本人用。鑑定では秒数を表示しない |

### 重ね方

- 同じ分類内の同一効果は加算、別レイヤーは乗算を基本とする案。例：基礎18、接着＋8%、有効な個体効果＋5%なら `18 × 1.08 × 1.05 = 20.412`。エンチャントが漏出防止ならこの計算には入れない。
- 部品を外すと、その部品による性能・重量・判定だけ解除する。再鍛造で変更する対象はModifier。修理・部品交換で熟練度とEgoの履歴を消さない。
- Ego／Abilityはレアリティなし。Modifier／Skillにはレアリティを設定できる。発動条件はPassive＝装備中、Active＝使用時、Passive+＝取得済み。

### 耐久と修理

| 処理 | 仮値 |
|---|---|
| 攻撃の有効命中 | 近接0.20、投射は発射成立で0.12。空振りした近接は0 |
| 盾 | 遮ったダメージ×0.04。元の攻撃が無効なら0 |
| 防具 | 実際に軽減したダメージ×0.02。命中した枠だけ |
| 道具 | 有効な加工・採取1回につき0.10。品ごとの指定を優先 |
| 耐久0 | 修理まで使用不可。消滅しない |
| 自己修理 | 1回で最大耐久の約3〜8%。熟練度を稼ぐための性能補正は無し |
| NPC・整備ロボ | 材料と設備条件が揃えば約60〜100%まで回復する案。個体履歴を維持 |

修理価格、消耗量、装着条件は本番経済と一緒に確定する。

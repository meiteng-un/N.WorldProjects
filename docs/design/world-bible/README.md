## 状態と優先順位
- 【確定】制作者が方針を了承。実装済み・検証済みを意味しない。
- 【仮】目安・候補・採用検討。数値や仕様の確約ではない。
- 【未定】今後決める必要がある。
- 【余白】意図的に明かさない。自動的に設定を創作して補完しない。
- 本文は原則【確定】。仮・未定・余白は明示する。
- 後の明確な訂正を優先し、旧案の単純併記で矛盾を作らない。
- 旧ログ008/009は雰囲気・描写の一次資料。現在の運用ルールは今回の聞き取りを優先。旧ログの有限電力・昇降機の限定運用を現在のホテル全体の確定制約にはしない。
- 既存の[N系解析](../../systems/n-gimmick-catalog.md)は過去時点の技術資料。現在のScene・実装を再調査したものではない。N系全体の完成度6〜7割という評価も制作者による当時の目安。
- **地図・平面図・座標配置・探索ルートの設計は制作終盤まで保留。本初版では作成しない。** 階用途表は空間配置図ではない。
- 「何でもできる」は長期目標。全構想を初期リリースの必須要件にしない。
- 実装、Scene適用、保存、Udonコンパイル、Desktop/VR、多人数検証は別々に記録する。本初版は設定文書のみ。

## 要素の相関（非地理）
| 起点 | つながる要素 | 位置付け |
|---|---|---|
| ホテルでの暮らし | 食事・娯楽・交流・飼育・製作 → SAN回復・関係・愛着 | 探索しない滞在も成立 |
| 外域探索 | 知識・装備・気象判断 → 採集・狩猟・撮影 → 保存・加工・展示・売買 | 危険と美しさ、帰還先の日常 |
| 素材 | 薬・料理・道具・設備 → 能力解禁/強化・暮らしの充実 | 資源不足でホテルを崩壊させない |
| 依頼・物資提供 | 貢献度 → 待遇・品目・設備・区域・VIP資格 | 個別NPCの好感度/信頼度とは別 |
| 使い込み・手入れ | 所有物個体との愛着 → 稀な能力発現・成長 | 素材は対象外 |
| 端末 | 認証・通信・依頼確認・転移・図鑑・資料・収納アクセス | 腰装着の必需品 |
| N.AreaCullinger | 区域とY範囲 → 描画/動作負荷制御・移動系への区域情報 | 接続の実装状況は別途検証 |
| 移動系 | 階段・N.ElevatorSystem・N.NavigateHierarchySystem → シームレスな生活/探索 | 再利用Border・映像境界は制作中の構想 |

# 要素・ルール設計
本書は設定・要件。機能の実装済み一覧ではない。

## 時間・永続性
| 対象 | 時間/保存の方針 |
|---|---|
| ワールド時刻 | 現実同期。睡眠管理は設けない |
| 空腹・渇き、飢餓継続、死亡後の保護30分 | 滞在時間のみ。退出中停止 |
| 肉体系の期限効果 | 原則滞在時間、死亡で消失【基本方針】 |
| 魂・精神系の期限効果 | 原則実時間。個別仕様優先 |
| インベントリ期限拡張 | 実時間、死亡後も持続 |
| VIP・一般客室・レンタル | 実時間契約 |
| 依頼期限、栽培、時間のかかる加工、野営結界 | 退出中も実時間で進行 |
| 利用制限の残り期間 | 滞在中のみ減少、場所不問 |
| 会話・文字通信ログ | 退出まで。会話は聞こえる範囲のみ記録 |
| 資料・図鑑・連絡先・個人設定・進行 | 再訪後も保持 |
| ペットの共用所有解除 | 所有者の実時間での不来訪が数か月【具体期間未定】 |

## 体調・死亡・再訪
- HP・MP等の大半は自然回復し、特定の飲食・薬・設備でも回復可能。全項目が回復するという意味ではない。シールドは標準で非被弾自然回復しない。
- 空腹・渇きは全区域で進行。初めは体力・能力低下、数日の滞在累計で死亡へ。死亡で空腹・渇きは解消しないがHP等は全快。
- 無料携帯食で満腹側の最大値の10%まで最低限回復し、水は無料。死亡後30分は飢餓・脱水ダメージ無効。
- 怪我・毒・汚染等の継続/完治は状態ごと。軽中度は注射薬・ポーション等。VRChatterの本格治療・入院は不要。住民の大半はある程度治療でき、医師相当は雑用ロボットと1〜2NPC。常設医務室はなく空室を臨時利用。
- 死亡はゲート復帰。通常の退出/切断からの再訪は原則前回地点。個室や主不在の招待VIP室等は室外。乗車中の自然な復帰は未定。外域復帰に保護時間は付けない。
- 収納済みの所持品は死亡でも保持。外へ出した品は現地に残り、一定時間内なら回収可能。乗り物内部などの保護場所は消滅対象外。個人所有品の自動回収規則を優先。

## SAN・感覚・操作
- N.StatusSystemに精神消耗/正気度項目ありとの制作者申告。場所・状況で減少量/速度を補正。ペット、美食、ホテル滞在、娯楽、入浴、自己修理等で回復を促す。
- 低SANは視覚・音・能力・異常からの認識されやすさ等へ段階的悪影響。最低でもそれ自体で死亡/強制帰還しない。ホテル内は演出を抑える。
- 一部の日本/神話系異常の痕跡を認識しやすい利点あり。MP等を使う端末撮影でも発見でき、低SANを必須にしない。
- 常時HUDは標準非表示。眼鏡/コンタクトなどの装備でHUD利用可能。端末で詳細確認可能。危険度は外見・挙動・知識で判断し、詳細には解析能力/端末。
- VR優先、Desktopも可能な範囲で代替操作。装着物位置・大きさ、利き手、UI、音量、通知等を保存。
- 外域ホラーの簡潔な事前案内、点滅/歪み/大音量の個人軽減設定。狩猟解体の直接的な血・内臓表現は抑える。
- ジャンプスケアも使用可能。イベント参加や探索を強制しない。

## 端末・転移・通信
- スマホ/シーカーストーン的端末を腰へ必須装着。失くしても戻る。本体の故障/電池切れなし。腕時計型は検討中。
- 転移には別系統の特殊エネルギー。単3充電池1〜2本、通常4〜5回【目安】。人数/質量で消費変化、車両ごとは約2回【目安】。
- ホテル帰還で無料ワイヤレス充電が自動開始し、徐々に回復。有料急速充電なら数秒で満充電。
- 行先は主に4人が指定した安全確認地点/拠点。一般PLによる追加不可。ホテル等の指定区域内は無消費。操作が間に合えば即時緊急脱出。
- 端末は依頼確認、通信、図鑑、資料、写真、地形記録、収納アクセスなどを統合。**地図の実制作は終盤**。
- 連絡先は原則対面で端末をかざして交換。音声/文字、個別/一斉。音声は本人向け。音楽は本人向け/周囲再生可能で、後者は生物を引き寄せ得る。
- 拒否/ミュート/削除あり。NPCは予定・関係等で応答が変わる。通信記録の任意資料化はなし、必須物語情報の一部のみ自動Tips/メモ。
- パーティーは端末接近で結成。NPC/ペットも登録。自動共有＋項目別の公開調整。バイタル/位置/転移残量の共有は暫定採用。
- 切断は所属を残し接続なし表示、同一インスタンスへ復帰。リーダー退出でも維持。離脱/除名/解散可能。別インスタンス共有は対象外。
- ホテルから遠隔支援可能。通信障害あり。古い値は最終受信からの時間などで判別可能。音声通信等の技術成立性は未検証。

## 所持品・収納・所有権
- 初期は鞄/ホルスター/車載収納。鞄は容量・重量・サイズ制限。一定荷重から徐々に遅くなり、上限で追加収納不可だが移動可能。
- 異次元収納は材料を薬化し服用して恒久解禁。適性差で拒否せず条件を満たせば誰でも取得可能。
- 個室の機械と能力は使用者本人の同じ個人インベントリへアクセスし、中身/容量を共有。招待客も自分の収納へ接続。機械は能力未解禁でも利用資格があれば使用可能。
- 一度個室契約で保管庫を持った人は契約終了後もロビー/入口の設備から出し入れ可能。中身とVIP配置データは保持。
- 個人異次元収納は時間停止。8Fの物理保管庫は時間停止ではなく保存期間延長。
- 容量/重量/物のサイズに制約。枠拡張で容量/重量もある程度増加、収納サイズ強化は別。
- 期限拡張は上限まで「拡張/延長」を選択。同じ拡張枠で期限統一。新期限=(既存枠数×残時間＋追加時間量)÷拡張後枠数。既存3枠各2分＋新規1枠30分→4枠各9分。延長のみは追加時間量を既存枠数で配分。単位/上限/重量との係数は未定。
- 拡張失効時は中身維持、新規収納停止。超過枠は取り出すと非表示。機械強化は機械に永続、利用者の標準上限へ恒久定着しない。機械で超過収納後も能力から取り出せるが追加収納停止。
- 生きた動物/魚も収納可能で捕獲/同意不要。ただし一定以上の大きさの知的生命体/NPC等は不可。閾値未定。
- 外の物は誰でも拾えるが、認証所有品の無断収納/持ち逃げには麻痺。落とし物として回収すれば所有者収納へ帰還。素材・料理・一部消耗品は防犯対象外。
- 貸与は許可制、借り手収納も一時利用可。借り手の退出で返却。貸し手が先に退出しても借り手の在室中は臨時所有。
- 所有道具等は距離/時間による自動回収を想定/設定可能。個室保管庫優先という表現は、後の決定で同一個人収納への機械アクセスと整理。未解禁者のレンタル品は再入場時復元案。
- 回収不能な状態は基本的に作らない。指定個室位置への出現/ロビー召喚は万が一の例外で、通常機能にしない。保険・専用回収サービスなし。
- 端末でホテル外から収納品を召喚/新規素材を送付する際は転移電池を消費。召喚時に送還分を物へ宿し、召喚品の返却は追加消費なし。

## 経済・契約・処分
- UdonChipsは共通通貨、N.GameUdonChipsは娯楽通貨。固定レート・手数料ありで相互交換。
- 依頼/売却/滞在・外域活動手当で収入。手当は屋内遅/屋外速、時間帯・気象等で補正。原住民と来訪者で通貨共通。
- 住民は超格安、一般来訪者は通常、迷惑利用者は高額。住民1/VIP0.9/一般0.75/迷惑0.2は待遇目安で料金倍率ではない。
- 貢献度はコロニー全体への貢献。滞在だけで上昇せず、上限あり、上げにくい。台詞/価格/品目/設備/立入/依頼/飛行解禁等に作用。
- VIPは貢献条件＋通貨の実時間サブスク。一般個室も実時間契約、1室3〜4人【目安】、招待/料金分担可。期限後は荷物保護して室外。
- VIP室は仮設次元の持続自室、一般室は構造から別で配置は再入場時リセット。VIP配置プリセット最大3件、家具/一部照明/小物のみ、壁床固定、設置量制限。
- 部屋主と編集許可された招待客が模様替え。主は退出させられるが上位権限者は不可。管理者は所有者として全権限を持つが通常無断入室しない。
- ホログラムケースは収納中の実物を展示し、取り出すと消え戻すと再表示。鮮度維持に利点、高額。
- レンタルは実時間、端末で延長/任意自動更新、期限は警告後帰還回収。破損しない。個体買取で愛着/履歴継承。
- PL間売買/譲渡は可能、双方了承の手段あり。カード・ダイス等賭けあり/なし。直接アイテム賭けは検討案、採用時は自己所有の譲渡可能品のみ。
- 軽い違反は自動検知し罰金/設備区域制限。管理者等は永久BAN判断。制限は滞在時間で解除、支払いで短縮。任意の違反表示タグ装着中は減少速度が僅かに上昇。
- 運営は4人の話合い/その場の権限者、投票も可能。常に全員参加を必要としない。

## NPC・会話・物語
- 個人好感度と信頼度は独立、通常不可視、特殊アイテムで可視化。NPC同士の関係値/関係は原則固定。性格で好き嫌い・怒り/許し等が異なる。
- 初撃の好感度低下は軽く連続攻撃は急増。ホテル内はダメージなしでも行為に反応。謝罪/行動での修復は仮方針。
- 数週間不在なら心配、数か月〜年で少し疎遠。具体的な関係値変化は未定。切断自体と約束中断を区別し、後者は関係低下し得る。
- 基本PL発の選択分岐・フル音声会話。一部の返答だけ関係値に作用。親密/条件でNPCから声掛け、会釈、権限でお辞儀。
- NPC1名＋PL最大5名で話題共有、他者は聞けるが空き待ち。無関係な割込みに初回注意、反復で無視、関連質問には返答。
- 独立字幕なし。通常の対話選択UIと端末ログ方式を備え、ログ画面表示中は通常UIを隠す。
- 贈り物は好み/品質で反応、連投減衰/拒否。食事/ゲーム/釣り等へ誘える。個室招待必須、常時許可は極めて厳しい関係条件＋個別出来事＋明確な許可。
- 深い友情/一部恋愛あり、PLごと独立し独占なし。個別会話/イベントも本人だけに隠さず周囲から分かる。
- NPC発の誘いは原則滞在中。断り方で影響、無視/約束破りは重い。切断でも同行/約束中断は関係影響あり。途中再開せず、その機会は終了して再度別機会へ。
- 同じNPCの個別イベントは順次、他人は待機/同行。関係固有進行は本人のみ、同行者の一般進行は保留。
- 大規模メイン2〜3本＋日常/サブ/季節イベント。具体題材未定。地形配置はほぼ不変、進行差あって同行可、条件達成者は個別記録、クリア済みは助っ人として台詞変化。
- 豪華なクリア報酬は少なく、道中の獲物等が主。再同行で通常の取得物を奪わない。バッドエンド/住民死亡は設けず、クリア後も同じ日常が続く。
- 物語は世界を救うのでなく、この世界の住民には元から日常だったものへPLが加わる体験。

## 依頼・取引・知識
- 依頼元はNPC限定。受注は会話、端末は受注済み確認。数の上限なし、9割以上期限付き、期限は実時間。
- 通常は嗜好品/趣味/材料/調査等。稀な高緊急度も相対的必要性で、未達成でも緊急生産/4人が対処し重大被害なし。
- 失敗は無連絡で信頼等低下、端末連絡で僅少、直接連絡なら更に僅少。延長/数量変更/キャンセル交渉はなし。受注前辞退は悪影響なし。
- 共同達成可。代表者が報酬受領後みんなで分配し自動分配しない。手渡し/箱籠/遠隔納品可。一部は品質/鮮度/産地条件。
- 売買は手/箱籠に品を置き査定、了承後成立。了承前に取り戻し/追加/交換して再査定。別売買画面への切替より自然な動作導線を重視。
- 通信障害時も二重取得/消失を避ける取引整合は設計要件で保証検証は未実施。
- 外の生存者は初対面対応共通、数十回の取引で態度/交換条件/特別品が緩和。襲撃/騙し/救助要請は遭遇コンテンツに入れない。
- 物々交換基本、ホテルと交流する相手は一部通貨可。拠点/専門で品目・要求品が異なる。共通交換資源は未定。
- 図鑑は撮影/解析/条件違いで段階開示、購入可、共有は解明済み段階を追加更新。入手経路や自分で未確認かの機能差なし。
- 推測/古い情報/条件不明も記録。収集完成は任意、収集率報酬あり。ホテル未知の発見は匂わせのみで専用報告報酬なし。
- メモは撮影→文字解析の演出で手動保存、資料集は永続しコピー共有可。実OCRの採用を意味しない。
- 怪異対処は試行発見約4割【目安】、残り探索/売買情報。メモ所持は実行条件でなく方法が合えば成功。

## 採集・製作・農業・飼育
- 素材/生物はインスタンス共有、量と高頻度再出現で争奪回避。獲物一頭分の量、鮮度で過剰採取に意味を持たせすぎない。
- 物理接触可能な対象は素材化、幽霊等は特殊品で物質化。退避しかない少数怪異の約半分に物質化が通用、そのうち約6割は使用だけ、約4割は場所時間等複合条件【割合目安】。
- 製作は浸す/乾燥/刻む/加熱/配合等。NPCは一定品質保証、機械均一、自作は失敗〜大成功。工程出来が主で運/熟練も影響。熟練は分野単位、完成品質で増減。
- 材料品質/鮮度/産地も影響。品質は価格/効果量/時間/性能等に反映。レシピ外の代用/配合も可能、正解以外すべて失敗にはしない。未取得でも正手順で製作可。
- NPC買取は品質/鮮度/関係補正等。需要/季節/大量売却で価格変動は原則なし。通常品は補充、希少/季節品に在庫条件。
- 失敗品も使えるが結果不明/大きな効果振れ。明瞭な失敗と一見成功品が混在。渡せるが本人使用なしで強制効果不可。
- 加工は退出中も進み、過乾燥/漬け過ぎ等あり、高価な機械/NPCは適切に停止。共同工程は各担当の結果反映。
- 一般区域の設備は誰でも利用、購入で個室設置。農園は空き無料、レンタルで期間確保、育成中保護。種肥料は製作/採取/購入。
- 収穫は育て主の物、売却等で通貨/貢献度。作物は退出中も成長し放置で枯死/品質低下。機械管理可、人の作業で品質変化。他PLの世話も可。
- 釣りは場所/時刻/天候/餌に対応。異常下のみの獲物、空間に針が掛かる体験も。
- ペット/魚は飼育繁殖可能。給餌資材があれば自動給餌、愛情/懐きは自動では変化せず手世話/遊び/一緒の時間で変化。
- 餌切れは衰弱→病気/死亡へ。衰弱時は高価な薬等で回復、寿命延長薬あり。進化は環境/薬/時間/確率、分岐あり、形質は一定確率で遺伝。
- 個室は個人所有、共用水槽育成も可、共用世話で貢献。所有者固定と懐く相手は別。
- 共用の取り出し/売却/譲渡は主と管理者のみ。数か月不来訪で無主化し引取り可。個室ペットはこの譲渡対象外、長期放置死は「マナに還る」仮表現、特殊個体に例外。
- 飼育時間経過の現実性は採用するが、オフライン処理・共有保存の技術は未検証。

## 装備・能力・愛着・戦闘
- 道具/武器は非常に壊れにくい耐久制、ゼロは修理まで使用不可で消滅なし。自己修理は修復率低く専門NPC/ロボが有利。自己修理はSAN回復/愛着に寄与し直接の性能ボーナスなし。
- 所有物は素材以外すべて個体×PLの愛着対象。一定値から稀に付喪神的な能力。通常鑑定不可、高額機械でも曖昧文で数値なし。
- 扱い/用途の履歴で能力が変わり成長、新用途の長期継続で追加能力。複数能力には途方もない時間。修理/部品交換でも履歴継承。
- 譲渡時の能力はほぼ残らず残っても元の数%。意図的放棄/譲渡後の関係再建は難しい案。貸借で変化させない案。落下/死亡は愛着減少なし。長期未使用は僅かに減少、消滅はしない。
- 能力は条件で誰でも習得、主に素材薬化。大半は既存NPCの誰かが取得済み。装備中/条件発動の効果、飲食/特殊品/施術の期限効果、非常に特殊な恒久効果。
- 基本加算/乗算、一部上書き/下位終了。能力装備枠なし、MP等が許す同時数、最大4〜5種程度【目安】。行動訓練成長＋装備/薬/食事補正、共通訓練上限＋特別補強は暫定。
- 剣/弓/銃/魔法/拳/罠等。弾薬は消費、購入/製作/採取。間合い重視。逃走/迂回は十分な速度等が必要。
- PvPは合意時のみ。外ではNPC/ペットにもダメージ、ある程度シールド。住民の死亡展開なし、危機は素材とNPCだけ先に帰還/特殊NPC救援。PLシールドは装備/能力で取得。
- ペットは戦闘死あり、装備/強化で危機時強制帰還等の保護可能。
- アバター衣服は変更せずワールド装備で効果。寒暖/濡れに装備等で対処。能動装備は動作中消費、一部のみ補充/交換。
- 通常飛行/コライダージャンプは異常エネルギーで不可。能力/品/乗物の飛行解禁あり、天候/区域で制限。泳ぎ/潜水/酸素/水圧対策、水中異常/資源も構想。

## 車両・野営・環境
- 購入/レンタル時認証、車/二輪/船/飛行系等。積荷保持し自動帰還/呼出し可。死亡後端末で待機/帰還選択。道路/天候/異常で迂回か車載転移で車庫へ。
- 走行燃料/電気と転移エネルギーは別。最後1回分段階で乗員/積荷ごと強制帰還し、回収不能を避ける。
- 携帯キャンプセットで極小フィールド。測定で薄いエネルギー地点を選び平坦/障害物なしなら自由設置、推奨地点あり。
- 高価な測定でも極稀な理不尽は残る。測定機の外付/別売詳細未定。火・車両・散逸する力等で接近しにくいが絶対安全ではない。
- 高額な散逸/結界で半日程度【目安】安全、実時間で期限。1時間前警告、30分前から5分毎、周辺異常でも撤収警告。退避はPL判断。延長可だが周囲変質の危険から非推奨。
- V睡/睡眠は雰囲気のみでステータス影響なし。セットは持ち帰り、結界は期限消滅。他者の片付け協力可能、防犯は所有品規則。
- 天候は現実連動の日も独自急変もあり、区域差含め全員同期。季節の現実行事＋独自現象/活動期のイベント。季節自体の変化は未定。
- 建物の一部で鍵/電源/障害除去。解錠等はインスタンス共有・初期化、個人記録は保持。別解と指定必須手段を併存。大規模地形破壊/自由建築はなし。

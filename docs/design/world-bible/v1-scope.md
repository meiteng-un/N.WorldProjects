# V1到達目標・段階方針
更新: 2026-10-18 / 制作者指定。世界観の最終構想と初期完成条件を分離する。

## バージョンの目安
- 現在は0〜0.2程度という制作者の暫定評価。実装率を測定した数値ではない。
- V1: R・7F・B2・3Fを完成させ、ギミックはプロトタイプ状態でも実際に動作する段階。
- V1以降: スマホ型等の端末形状や細かな体験へこだわる段階。
- V5〜V6程度: メインストーリー等を実装する段階という将来目安。日程や確定リリース契約ではない。
- V2〜V4の内容は未定。勝手に割り当てない。

## V1の端末
- 当面はRTab_Standで代用。世界観上の魂認証端末の最終外観と、制作中の代替UIを区別。
- 既存RTabsを活用し、必要なアプリ追加・ギミック接続を検討する。アプリ追加自体の実装はまだ行っていない。
- [RTabsのアプリ追加手順の参考（公式サイトに掲載されていたとの制作者提供）](https://docs.google.com/document/d/1XuPlGBnWKKYuEkXR9TMJauyEE7O8xlekXWhJtDtw_i8/edit?tab=t.0)
- 取得確認（2026-10-18更新）: 公開テキスト出力で本文取得・ローカルAPI照合済み。図版の設定値とライセンスは未確認。[アプリ追加・連携調査](../rtab-app-integration.md)を参照。

## 進め方
1. 対象4フロアに必要な既存ギミックの接続・動作を優先し、すべての世界観要素をV1へ詰め込まない。
2. 不足品を最小単位で追加。未整備階は閉鎖を維持。
3. N.AreaCullingerの全域Collider配置・完全停止復元は終盤。プロトタイプの明白な不具合は先に修正。
4. 最低限の権限・参照・保存・同期・入力・負荷を確認するが、全構想の最終最適化とは区別。
5. 各ギミックのV1必須/後回し一覧・対象端末アプリ一覧・受入試験は今後実環境を確認して具体化する。既存の未検証機能を完成扱いにしない。

地図・配置図の制作は引き続きワールド制作終盤まで保留。世界観設定は[統合設計書](README.md)を参照。

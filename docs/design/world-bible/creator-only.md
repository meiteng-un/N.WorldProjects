# 制作者用：裏設定・余白・保留
**一般向け資料に含めない。** 本文の存在を住民全員が知っていると解釈しない。

## 中核人物とコロニー
- Naturlinが単独行動→たまもぉ→Huyuki→Aonekoの順に仲間が増え、4人で車移動中、偶然立地の良いホテルを発見。旅で初対面。
- 出会い/同行の詳しい経緯、細かな役割分担は【余白】。全員万能型で、能力・技術・経験・装備・準備で突出。勝手に専門職や過去を割り当てない。
- 住民死亡は物語/イベントでも採用しない。特殊NPC/4人NPC版が救援、あるいはNPCだけ素材と先行帰還。
- 一部特殊NPCはVRChatter兼原住民。その成り立ちは【未定】。全4人が該当するとはしない。
- 4人の関係を勝手に恋人/家族へ固定しない。NPC相互の好感/信頼/人間関係は原則固定。
- ロボは4人/技術者が作った独立疑似人格の補助機械。警備/整備は専任、雑用は受付・販売・配達・飼育・農業・観測等を交代。単一中枢AIの端末とはしない。

## 安全の仕組み
- 災厄由来の物質/資源/現象を利用。4人と一部NPCは知るが一般来訪者には不明。
- 敷地境界に沿う特殊フィールドは屋上も含む。雨雪は入るが有害性を除く。敷地すぐ外は危険、外周には距離依存のドーム状軽減もある。
- 内部の異常現象は完全無効化。持込物質の大半は無効化し、消せない性質は非活性化。外へ出すと時間/トリガーで再活性化。両者を混同しない。
- 一部生物/怪異は接近時に方向を惑わされホテルへ近づけない。内側からは不可解な迷走に見える。
- 魂に結びついた端末で認証された住民/来訪者は接近阻害を免れる。外部NPCは認証者の同伴で連れて来られる。
- 防護は半永久で資源補充を生活維持の必須課題にしない。外の資源は備え/豊かさ/遠征等が目的。
- 工業資源も生成可。希少/異常/天然固有成分も無理すれば生成可だが消費桁違いで常用不可。
- Naturlinと親しい知性ある異常存在が防犯を担う。取り決めに沿い自己判断風。普段は存在に誰も気付かず、違反者だけ恐怖体験、姿/正体不明。違反停止/無断室から退出で収まる。NPC全員が知る警備機能にはしない。

## 建物の用途（地図ではない）
ホテルは一部山に埋まり、1Fが岩肌から露出。山中/中腹を隠し区域として利用。

|---|---|
| R | 天体観測・農業・風力・洞窟住居・バー・集会・焚火、防護下の天気 |
| 9F | 管理室、サーバールーム/コンソール的な超技術 |
| 8F | ホテル規模の物理倉庫、食料/素材/資源/武器等 |
| 7F | 管理者・関係者の完全な特別個室 |
| 6F | VIP/イベント関係者、共通廊下の先は転移応用の仮設次元個室 |
| 5F・4F | 主に来訪者向け一般客室 |
| 3F | フリースペース。各種公共ゲームを各1セット置くが娯楽専用階と固定しない |
| 2F | NPC/ロボが対応する売店・商業区域 |
| 1F | エントランス、車両等 |
| B1 | 制限区域、重要設備・サブコア |
| B2 | プライベートプール・温泉・サウナ・バー等 |
| B3〜B8 | 隠し階層、主にNPC居住・大規模設備/保管庫等。詳細未定 |
| B7またはB8 | 本当の総合コア、発電/エネルギー生成/防護/転移等【設置階未定】 |

隠し区域への入口はB1/9F/Rなどの関係者区域から。管理者同行・許可・イベント進行等が必須でVIP/貢献だけで自由立入にはしない。
外観/生活区域は元ホテル8割・継足し配線等2割【視覚目安】。特定区域で超技術、隠し区域は工業的な方向を強める。細かな住居/生活空間は未定。
主な視覚参考はEndfield/Satisfactory。設定・アセットの無断複製ではなく方向性の参考。アークナイツ/AC/PSO2NGS/Enshrouded/迷いの森/鳴潮/NTE/裏世界ピクニック等も着想参照で、固有設定そのものの採用ではない。
個人用娯楽品スキャン・ゲーム選択と公共セットは別。Ludo/チェス/オセロ/チンチロ/ヨット/ポーカー等、各ダイス/カードにN.DynamicObjectを付ける構想。

## 区分して残す未決事項
- 【未定】災厄の名称/総数/分類、地域名、コロニー別名、エネルギー正式名/通称/型番。「マナに還る」は仮表現。
- 【余白】災厄の全貌は解明し切らない。恐怖/不可解/理不尽を単一原因へ還元しない。4人の出会い詳細・役割も意図的余白。
- 【未定】メイン2〜3本の題材・展開、NPC個体名簿/性格/会話/予定、同行者の個別イベント進行。
- 【仮】猫又以外の進化案（星メダカ/浮遊メダカ等）はアシスタントの提案例で未採用。固定生物一覧へ混ぜない。
- 【未定】すべての数値調整：価格/倍率/充電時間/貢献閾値/容量/重量/成長/確率/保存期間等。本書の約・程度・目安は初期バランス確約ではない。
- 【要整合】一般客室の再入場リセットと、購入家具/栽培/個室ペット/自動設備の長期保存範囲。VIP室の永続は確定だが全一般室を永続へ変更しない。
- 【要整合】拾える/盗めない所有認証の具体境界、無断持ち逃げと回収/貸借の判別、罰則の誤判定防止。
- 【要検証】切断時の取引・共有ペット・オフライン進行・個人別仮設部屋・永続保存・音声通信・同時NPC会話等の技術成立性/負荷。
- 【技術保留】N.ElevatorSystemとN.NavigateHierarchySystem、再利用Border2個・中間階の転移先リアルタイム映像・ブラックウォール風演出は個別制作。ここで完成扱いにしない。
- 【技術保留】N.AreaCullingerのコライダー＋Y範囲、区域重複、選択最大2件のScene編集等はソース変更と実動作検証を区別。
- 【終盤まで保留】地図/平面図/座標/配置ルート。図鑑・探索済地形記録の機能構想だけ維持。
- 今後の質問は関連事項3〜5件ずつ。既決事項の再質問や、実装に影響しない細部の過剰な分岐を避ける。

## 更新履歴・撤回された旧案
- 来訪者を救世主/ホテル存続に必須とはしない。
- インベントリ期限強化は当初「滞在中のみ」だったが、魂系と決まり実時間へ変更。
- 個室保管庫は独立容量ではなく本人の同じ収納へのアクセス装置。
- 機械強化は本人への恒久強化ではなく機械に残る。
- 外での切断再訪は現地・保護なし。死亡のゲート復帰/飢餓保護とは別。
- 未知発見の報告報酬システムは採用しない。図鑑収集率報酬とは別。
- 受注はNPC会話のみ。端末は確認/連絡/納品等であり受注端末ではない。
- 高緊急度依頼失敗でホテルを崩壊させず、連絡ありの未達成でも関係低下は僅かに残る。
- シールドは標準で非被弾自然回復しない。レンタル品は破損しない。

# Decision Records

設計や実装方針が確定した後、その決定と理由を短く残します。

## テンプレート

```md
# ADR-XXXX: 決定タイトル

- Status: Proposed / Accepted / Superseded
- Date:
- Related Issue/PR:

## Context

## Decision

## Alternatives considered

## Consequences

## Verification required
```

決定を変更した場合は既存記録を削除せず、新しいADRから旧ADRを参照してください。

# 防具 / Armor

生成済み試作64件。軽減率は対応部位への命中に使う案です。V1で部位判定を使わない場合は、胴装備が通常攻撃を代表し、頭・手・脚は環境耐性のみ。盾は実際に遮った攻撃だけに適用します。

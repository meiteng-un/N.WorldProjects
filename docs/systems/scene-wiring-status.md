# シーンの接続状況

対象は N.Worlds Project -001。過去のUnity読み取り結果を整理したものです。現在の割り当ての再測定や実機試験は含みません。

| 系統 | 確認した参照 | 保留・確認候補 |
|---|---|---|
| ドア・受付 | ドア → 物品管理、個室復帰、権限台帳。ハンドル・カード認証・転移入力 → ドア | 共通フェードAnimatorは空欄 |
| Elevator | 階操作盤 → 本体 | 操作音、移動開始・過積載音、部屋オーナー一覧。各階の配列と実機操作は確認対象 |
| IntegratedMenu | 追加2画面 → メイン、ローカルポインター → Console入力 | ボタンイベント・VR／Desktop操作確認 |
| ステータス | 称号・能力 → Status、Status → Abilityの死亡通知 | 補正の実機確認 |
| 物品・武器 | Inventory・Weapons → DynamicObject管理、Weapons → Status | 個体ごとのMAEE設定、取付、実機確認 |
| 釣り | 本番の釣り竿 → 物品・釣果。デバッグ側に天候参照あり | 本番側の天候参照は空欄だった |
| NPC・Quest | 本編カタログの割当 | 配置まで本接続は保留 |
| EntityAbilityState | 単独配置の状態コンポーネントあり | 調査時点でカタログ種別なし、DynamicObject参照0件 |

# External References

公開GitHub、X、YouTube、公開ドキュメントを、設計比較・API確認・実装方針の参考にするための記録です。

- [目的別参考URL一覧](reference-links.md)
- [X・YouTube参照記録テンプレート](social-video-reference-template.md)

## 対象URL

- GitHub repository / file / issue / pull request
- Xの単独投稿、スレッド、公式アカウント投稿
- YouTube動画、公式チャンネル、動画内の特定タイムスタンプ
- 公式ドキュメント、仕様書、リリースノート

## 必須項目

各外部参考には次を記録します。

- URL
- URLの用途を示す一言ラベル
- Source type: GitHub / X / YouTube / Documentation
- 投稿者、組織、チャンネル、リポジトリ所有者
- 投稿日または公開日、取得日
- 対象のブランチ、タグ、コミット、動画タイムスタンプなど
- ライセンスまたは利用条件
- 参照したファイル・セクション・発言・動画区間
- N.WorldProjectsでの用途
- 採用した考え方と、採用しなかった部分
- ソースやアセットをコピーしたか
- NOTICE、フォント、画像、依存ライセンスの確認状況
- 次回更新時の確認事項

## Analysis rules

XやYouTubeの内容は、投稿者の主張・紹介・体験談と、一次資料で確認できた事実を分けて記録します。

- Xは単独投稿だけで判断せず、可能ならスレッド、引用元、投稿者の公式リポジトリまで確認する。
- YouTubeは動画タイトルだけで判断せず、説明欄、公開日、チャンネル、該当タイムスタンプを記録する。
- 動画や投稿の長い文章・字幕・歌詞を転載せず、必要な範囲を要約する。
- リンク先が削除・非公開・ログイン必須になった場合は、その状態を記録する。
- 人気、再生数、拡散数だけでは品質を判定しない。
- 実装へ反映する前に、現在のUnity、VRChat SDK、UdonSharp、Naturlin規約との互換性を確認する。

## Discovery and quality filter

X、YouTube、Chrome、GitHub検索などで候補を見つけた場合も、次の条件を確認してから一覧へ追加します。

- N.WorldsのUI、UdonSharp、VRChat World、性能、検証に直接関係する
- 内容の出典、更新日、投稿者、実装または検証方法を確認できる
- LICENSE、NOTICE、フォント、画像、第三者依存の条件を確認できる
- 採用する場合の導入方法と、既存システムとの競合が判断できる
- 「参考のみ」「候補」「採用済み」を明確に分けられる

品質を確認できないリンクは、人気や投稿時期だけを理由に登録しません。

## 利用方針

1. 必要な箇所だけを読み、外部情報を無条件に取り込まない。
2. 参考・設計影響・コード流用を明確に区別する。
3. コードやアセットを流用する場合は、ライセンス条件と帰属表示を対象ファイルの近くにも残す。
4. 公開情報であっても、個人情報、秘密情報、非公開投稿の内容は保存しない。
5. 外部の実装を採用しても、Unity/UdonSharp/VRChat上の動作検証はN.WorldProjects側で別途行う。

## ステータス

- **Reference only**: 比較・設計の参考のみ
- **Candidate**: 採用可能性を調査中
- **Adapted**: ライセンスを確認して一部を適応
- **Adopted**: 採用と検証が完了
- **Rejected**: 条件・性能・互換性などの理由で不採用
